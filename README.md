# Bin Bypass — collector app demo

Interactive demo of the Bin Bypass collector app for Tasmania's Recycle Rewards 10c container refund scheme.

Bin Bypass units are solar-powered, six-container racks that mount in clusters at clubs, schools and parks, counting containers live over the mobile network. This app shows collectors where the containers are, what they're worth, and the best run to cash them in.

**Try it: https://jonogibson1.github.io/bin-bypass-app-demo/**

Open the link on a phone and add it to your home screen for the full-screen experience. The app is open — no login, no account, no personal data.

All sites, counts, stats and money figures are simulated demo data.
